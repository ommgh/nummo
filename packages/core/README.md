# @usenummo/core

The pure billing rules behind [nummo](https://github.com/ommgh/nummo): exact quantities, money in base units, billing periods, deduction order, credit systems, overage and proration. No I/O. Most projects use [`@usenummo/sdk`](https://www.npmjs.com/package/@usenummo/sdk) and [`@usenummo/config`](https://www.npmjs.com/package/@usenummo/config) instead. Licence: Apache-2.0.
