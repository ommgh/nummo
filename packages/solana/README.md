# @usenummo/solana

[nummo](https://github.com/ommgh/nummo)'s settlement adapter for Solana's native Subscriptions program: read plans and subscriber records; build activation, plan change, cancel, resume, top-up and plan creation transactions; prepare, send and confirm pulls. `@usenummo/solana/testing` exports `FakeChain`, an in-memory stand-in that follows the program's rules.
