# @usenummo/config

Pricing as code for [nummo](https://github.com/ommgh/nummo): `feature()`, `plan()`, `defineConfig()` and `usdc()`, with validation of the config document. Write a `nummo.config.ts`, then apply it with `npx nummo push`.

```bash
npm install @usenummo/config
npx nummo init   # writes a starter nummo.config.ts
```

See [the pricing config guide](https://github.com/ommgh/nummo/blob/master/docs/guide/pricing-config.md). Licence: Apache-2.0.
