# nummo guide

How to use nummo. The design documents one level up explain why it works this way.

1. [Quickstart](quickstart.md): charge a devnet wallet in under 30 minutes.
2. [Pricing config](pricing-config.md): features, plans, overage, top-ups, pay per use for agents, per-model token pricing, versions, and the on-chain ceiling.
3. [Billing flows](billing-flows.md): gating, AI model calls, agents paying per request (x402 and MPP), subscribing, upgrades and downgrades, top-ups, the customer portal, failed payments, webhooks, verify.
4. [Self-hosting and mainnet](deploy.md): processes, Docker, settings, email, rate limits, monitoring and alerts, backups, key custody, the checklist before real money, and what mainnet costs.

The REST endpoints, SDK methods and webhook events are listed in [doc 04](../04-api-and-config.md).
