# nummo

Open-source usage-based billing and entitlements, settled in stablecoins on Solana.

Plans, credit balances and a usage ledger with `check` and `track`, collecting USDC from the customer's wallet through Solana's native Subscriptions program. Non-custodial: funds move straight from the customer to the merchant.

**This package is a placeholder for the upcoming `nummo` command-line tool:**

```bash
npx nummo push     # apply your pricing config (nummo.config.ts)
npx nummo verify   # compare billing records with the chain
```

The SDK and config builders will be published under the [`@usenummo`](https://www.npmjs.com/org/usenummo) scope.
